# Emotion Spacing Skill

ReplyMateのLPやUIコピーでは、以下を常時意識する。

- 感情パートと解決パートの間に、必ず呼吸できる余白を置く
- モバイルでは2〜3行で読める塊を前提にする
- 不自然な自動改行を避け、意図した位置で改行を設計する
- 「説明」よりも「今の自分だ」と感じられる自分ごと感を優先する
- 恋愛攻略、駆け引き、相手を操作する印象を出さない
- 不安を煽らず、送る前に落ち着ける空気を作る
- CTAは押し売りにせず、自然に次へ進める強さに抑える
- 白黒だけで硬くしすぎず、セージやブルーグレーなどの微量な色を許可する
- 完全に均一なUIにせず、人間らしい余白や強弱を少し残す
- ReplyMateは恋愛相談アプリではなく、送信前エアバッグとして見せる
